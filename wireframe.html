Sidebar components
  • 1JIRA Ticket input — free-text; accepts ticket key (e.g. SCRUM-1) or natural language. Key is extracted server-side.
  • 2Repository Path input — absolute path on server. Defaults to "." if blank.
  • 3Context textarea — optional extra requirements forwarded to the Claude prompt verbatim.
  • 4Attachment buttons — open hidden <input type=file>. Files POST to /upload, returned id stored in state array.
  • 5Attachment chips — rendered after upload. Each chip shows a thumbnail (images) or doc icon, filename, and ✕ remove button (calls DELETE /upload/:id).
  • 6Generate Code button — POST /generate → receives job_id, opens SSE stream at /stream/:id. Disabled during active job.
  • 7Stop Execution button — visible only during active job. Calls DELETE /jobs/:id, then cancels EventSource.
  • 8Status badge — hidden at rest. Shows animated dot + elapsed timer when running; green dot + final token count when done.
Output pane components
  • ATab bar — Live Output and Changes tabs. Changes badge shows file count; hidden when 0.
  • BOpen in VS Code button — visible on Changes tab when diffFiles.length > 0. Triggers VS Code URI handler with the repo path.
  • CCopy result button — visible after job completes. Copies full result text to clipboard.
  • DLive Output panel — NDJSON events rendered as colored log lines: session (grey), tool call (blue), text (dark), result (green), error (red), done (muted).
  • EChanges / file tree — 230px left column listing every changed file with +/− stats. Click to select.
  • FDiff viewer — renders unified diff for selected file with gutter line numbers, +/− signs, and color-coded add/del/hunk rows.
